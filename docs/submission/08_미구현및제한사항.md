# 미구현 기능과 남은 제한

## 이번에 보완한 필수 기능

- F2004: 선택 추가 보고서의 수집·전문 청킹·small 색인·선택 접수번호 검색까지 연결했다. 실제 연간/분기 공시로 검증했다.
- F2005: 기존 large와 small 확장분의 합집합으로 연간 100건의 모든 4,856개 섹션을 검색한다. 전문 청크 120,008개의 비공백 본문 누락이 없음을 검사했다.

## 선택 심화와 서비스 개선

- F2013 독립 프론트엔드/서버, F2014 MMR, F2016 여러 종류의 출처: 미선택·미구현.
- F2015의 실제 5문항 비교는 보관했다. 혼합 확장 뒤 5문항 재실행은 하지 않았고 이전 실험임을 표시했다.
- 브리핑 UI 신규 생성 버튼, 저장 브리핑 100개 확대, 로그인·대화 영구 저장/삭제는 미구현이다.
- 임의의 과거 모든 연도/현재 채용·금리 탐색, 구조화 재무 수치 계산 엔진은 제공하지 않는다. 보고서 검색은 문서화한 접수일 스냅샷과 3가지 정기보고서 유형으로 제한한다.

## 제출 전 사람의 확인

공식 양식의 셀프 체크리스트는 output/제출문서에 작성했다. 현재 nano의 응답시간·최종 실제 실행, 실제 다른 교육생의 상호 점검, 지역·반·성명 입력은 남아 있다. 인용 번호 유효성은 모든 문장의 의미 정확성 보장이 아니다.
