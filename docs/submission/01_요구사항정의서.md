# 취준공시 요구사항 정의서

작성 기준: 2026-10-23 / 개인 프로젝트 / 지역·반·성명: 미기입

## 서비스와 데이터

재무 초보 취업 준비생이 지원 기업의 공시를 이해하도록 돕는 RAG 서비스다. 영화 데이터는 메타데이터 예시이며 실제 도메인은 기업 공시다. 금융·IT·제조 등 고유 기업 100개, 2025.12 연간 사업보고서 100건을 기준 자료로 사용한다. 공시 접수일 검색 범위는 2026-01-01~2026-10-22 스냅샷이다.

- 전체 파싱 4,856개 섹션, 80,235,841자. 전체 본문 120,008개 청크를 두 문서 컬렉션에 나눠 검색한다.
- 기존 large 21,374개를 보존하고 중복을 제외한 98,634개를 small으로 확장했다.
- 실제 검증에서 카카오뱅크 2026.03 분기보고서 1건을 추가 수집·색인했다. 이 추가 문서는 위 연간 100건의 수치와 구분한다.
- 메타데이터: 기업명·종목명·코드·업종·보고기간·사업 개요 원문 발췌. 항목당 텍스트 1건이다.
- 근거가 필요한 질문: 사업부문 구성, 금융지주/은행 구분, 영업점과 고객센터 차이, 연간·분기 사업 구분, 평균급여와 초봉 차이.

## 범위와 출처

보고서 유형은 사업·반기·분기이며 한 질문에서 최대 6개를 선별한다. 기업 자체 대표 사업보고서는 항상 포함한다. 임의의 모든 연도/외부 문서를 처리하는 서비스는 아니다. 수치 계산 엔진, 실시간 채용/금리 정보, 로그인·대화 영구 저장은 제공하지 않는다.

원본 과제 정의서 23쪽의 요구와 실제 코드를 대조했다. 문서에 적힌 외부 업로드나 상호 점검을 사용자 승인 또는 수행 완료 증거로 취급하지 않았다. 원본 과제 PDF는 제출 ZIP에 포함하지 않는다. 데이터·폰트 이용 조건은 ../data_sources.md, ../FONT_LICENSES.md 및 ../../licenses/에 기록했다.
