# 데이터 출처와 이용 조건

확인일: 2026-10-22. 이번 작업은 로컬 프로젝트 데이터 준비이며 외부 공개·배포는 수행하지 않았다.

| 데이터 | 제공 기관·출처 | 수집 경로 |
|---|---|---|
| 기업 후보·고유번호 | 금융감독원 OpenDART | 기존 `corpCode.xml` 수집 결과 |
| 기업개황 | 금융감독원 OpenDART | `company.json` |
| 사업보고서 후보·정정 여부 | 금융감독원 OpenDART | `list.json`, 사업보고서 A001, 최종보고서 Y |
| 공시 원문 | 금융감독원 DART, 각 공시 제출인 | `document.xml`로 받은 원본 ZIP 내 사업보고서 XML |
| 기업 사업 개요 | 동일 사업보고서 | 사업 내용 섹션의 원문 발췌. 생성 요약이 아님 |

공식 문서:

- [OpenDART 서비스 소개](https://opendart.fss.or.kr/intro/main.do)
- [기업개황 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019002)
- [공시검색 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001)
- [공시서류원본파일 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)

각 문서의 원문 링크는 `https://dart.fss.or.kr/dsaf001/main.do?rcpNo={접수번호}` 형태로 기록했다. 데이터에는 기업 고유번호, 보고서명, 접수번호, 접수일, 보고기간, 원문 링크와 수집시각을 남겼다. 검색 스냅샷은 2026-10-22까지이며 이후 정정본을 포함한다고 보장하지 않는다.

OpenDART 사용은 [공식 이용약관](https://opendart.fss.or.kr/intro/terms.do)에 따른다. 약관 제10조는 이용횟수 제한과 운영을 저해하는 접속에 대한 이용 제한을, 제16조는 서비스·관련 프로그램의 저작권 및 약관 외 저작권 사항의 관계법 적용을 정한다. 제19조에 따라 인증키를 제3자에게 제공하지 않는다. 공개 접근 가능하다는 이유로 모든 공시·첨부자료가 자유 재배포 가능한 동일 라이선스라고 가정하지 않는다.

약관 제23조는 공시정보가 공시 제출인의 책임으로 작성되며 제공 기관이 정확성·완전성을 보장하지 않는다고 설명한다. 앱에서는 보고기간과 원문을 표시하고, 생성한 취업 준비 제안과 원문에서 확인한 사실을 구분한다.

수집기는 직렬 호출·호출 간격·일시 오류 재시도·캐시를 적용했다. 원본 ZIP을 보관하고 파싱 결과를 별도 저장했다. 배포·제출 범위를 정할 때에는 이 약관과 해당 자료의 권리·이용 조건을 확인하며, 인증키는 제출물에 넣지 않는다.
