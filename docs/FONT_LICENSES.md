확인일: 2026-10-22. 글꼴 파일은 수정하지 않으며 눈누가 안내한 웹폰트 CDN을 통해 불러온다. 인터넷 연결이 없거나 CDN 접근이 차단되면 시스템 글꼴로 표시된다. 앱 하단의 '글꼴 출처 및 라이선스'에서도 출처를 확인할 수 있다.

## 본문·보조 문구 — SUITE(스위트) SemiBold 600

- 요청 링크: [눈누 스위트](https://noonnu.cc/font_page/1150).
- 제작: SUNN YOUN. 공식 소개: https://sun.fo/suite/
- 공식 저장소: https://github.com/sun-typeface/SUITE
- 저작권 표시: `Copyright (c) 2023, SUNN (http://sun.fo/suite), with Reserved Font Name SUITE.`
- 라이선스: SIL Open Font License 1.1. 공식 원문: https://github.com/sun-typeface/SUITE/blob/main/LICENSE
- 상업적 웹 사용과 임베딩을 포함해 OFL 조건에 따라 이용할 수 있다. 폰트만 따로 판매할 수 없으며, 재배포 시 저작권 표시·라이선스를 보존하고 수정본의 예약 이름 조건을 따라야 한다.
- 공식 라이선스 사본: [licenses/SUITE-OFL.txt](../licenses/SUITE-OFL.txt).
- 눈누 라이선스 설명에 SUIT 이름이 등장하므로 SUITE 공식 소개와 해당 저장소의 라이선스를 기준으로 확인했다.
- 사용 파일: `SUITE-SemiBold.woff2`, 실제 SemiBold 굵기(600).
- 웹폰트 주소: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2304-2@1.0/SUITE-SemiBold.woff2
- 파일은 변환·수정하지 않고 CDN을 참조한다. CSS의 `CareerBody`에 600 굵기로 등록한다.
- 적용: 본문, 목록, 안내·캡션, 소개 문구, 배지, 현황·수치, 입력창·버튼·기업 선택, 공시 원문, 인라인 코드 등 본문·보조 텍스트를 600으로 통일했다. 서비스명·기업명·영역 제목·질문 제목은 KCC간판체를 유지한다. 메뉴 화살표 등 아이콘에는 전용 글꼴을 유지한다.
- 폰트가 제공하지 않는 글자와 CDN 로드 실패 시 시스템 고딕 계열 글꼴로 대체된다.

- 적용: 서비스 이름, 기업명, 각 영역의 제목과 질문 제목. 본문·보조 문구는 SUITE SemiBold 600을 사용한다. 메뉴 화살표 등의 아이콘은 전용 아이콘 글꼴을 유지한다.

## 화면 색상과 출처 글씨 크기

메인 배경 `#FFFFFF`, 사이드바 `#EDF2FB`, 사이드바 선택·버튼·테두리 `#CCDBFD`, 본문 입력창·일반 버튼 `#FFE5EC`, 주요 버튼·본문 카드·토글 테두리 `#FFC2D1`, 제목 위 문구 `#FF8FAB`를 사용한다. 일반 버튼 테두리는 상태별 배경색과 같은 값을 사용한다. 첫 질문과 후속 추천 질문 버튼은 흰 배경에 `#CCDBFD` 테두리를 유지한다.

본문의 120% 글자 크기와 SUITE SemiBold 600, 제목용 KCC간판체는 유지한다. 글꼴 출처 토글은 중립색 테두리를 유지하며 내부 출처 본문·링크는 정확히 `16px`로 표시한다. `[취]` 아이콘은 제거했다.
