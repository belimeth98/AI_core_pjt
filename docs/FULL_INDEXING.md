# 현재 전문 색인 구성

기존 large 선택 청크 21,374개와 small 확장 청크 98,634개를 별도 컬렉션에서 검색합니다. 합계 120,008개는 연간 100건의 전체 4,856개 섹션에 해당합니다. 추가 선택한 분기·반기 보고서는 small으로 전문을 색인합니다.

현재 구조와 실행 증거는 [설계](submission/02_RAG파이프라인설계.md), [검증](submission/03_검증결과.md)을 기준으로 합니다. 두 모델의 코사인 거리를 직접 비교하지 않고 순위를 병합합니다.

이미 완료된 원래 프로젝트를 다시 색인할 필요는 없습니다. 새 PC의 재현 순서는 [README](../README.md)를 확인하세요. 새 임베딩은 명시적으로 허용해야 GMS를 호출합니다.
