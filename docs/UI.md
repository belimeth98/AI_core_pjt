# 화면 실행과 연결 구조

```bash
python -m streamlit run app.py --server.port 8502
```

- `app.py`: 기업 선택, 질문 입력, 질문 기록, 추천 질문 버튼, 원문 근거와 노트 다운로드.
- `src/pipeline.py`: 화면과 CLI가 공유하는 전체 파이프라인.
- `src/ui_support.py`: 표시·기록 재사용·다운로드 텍스트 보조 함수.
- `src/vector_store.py`: 기업별 색인 준비 상태.
- `assets/app.css`, `.streamlit/config.toml`: 색상과 글꼴 스타일.

초기 실행 시 저장된 `latest_pipeline_result.json`이 선택 기업·보고서와 일치하면 질문 기록으로 불러옵니다. 동일 질문은 같은 색인 지문에서 세션 내 기존 답변을 재사용합니다. 실패 시 기존 기록을 유지합니다. 색인이 없는 기업은 질문 입력이 비활성화됩니다.

질문 입력창 위의 **취업 준비 브리핑**에서 저장된 기업 요약·핵심 포인트·준비 제안·면접 연습 질문을 펼쳐 보고 Markdown 노트로 내려받을 수 있습니다.

`src.briefing.load_saved_briefing()`은 저장 파일의 기업·접수번호·보고기간을 확인하고, 원문 발췌와 형식을 재검증한 뒤 화면용 Markdown을 만듭니다. 다른 기업·기간의 결과는 표시하지 않습니다. 자료가 없으면 준비 안내를, 손상되었거나 검증에 실패하면 오류 상세를 숨긴 안내를 표시합니다. 브리핑이 없어도 기존 질문·답변은 사용할 수 있습니다.

이 경로는 저장된 자료만 읽으며 외부 API 호출과 파일 쓰기를 수행하지 않습니다. 새 브리핑 생성은 기존 CLI를 사용합니다. 화면 함수와 생성 함수는 모두 `src.briefing`에 있습니다.

```python
from src.briefing import load_saved_briefing
```

UI 테스트는 GMS·DART 호출과 색인 준비 상태를 모의 처리합니다.

```bash
python -m pytest tests/test_ui.py -q
```

## 기업 탐색과 여러 기업 사용

화면 위쪽의 **조건으로 기업 찾기**에서 사업·제품·서비스 조건을 입력하면 메타데이터 후보를 검색하고 조건별 원문 발췌와 함께 결과를 보여줍니다. 결과의 이동 버튼은 기업 선택을 변경하고 기존 기업별 질문 기록은 유지합니다. 재실행만으로 모델을 다시 호출하지 않으며, 검색 폼을 제출했을 때만 실행합니다.

현재 100개 기업 모두 공시 질문이 가능합니다. 색인 모델은 text-embedding-3-large(3,072차원)입니다. 저장된 취업 브리핑은 카카오뱅크·기업은행·신한지주·하나금융지주 4개 기업분이며 나머지는 CLI로 추가 생성할 수 있습니다. 기업별 브리핑은 `data/processed/briefings/{corp_code}/{receipt_no}.json`에서 읽고, 해당 경로가 없을 때만 기존 연습 결과를 확인합니다. 브리핑 읽기와 다운로드는 모델을 호출하지 않습니다.
